# Certified Kubernetes Administrator (CKA) Learning Repository

## Overview

This repository contains my notes, hands-on exercises, YAML manifests, commands, and learnings while preparing for the Certified Kubernetes Administrator (CKA) certification.

The content is based on the CKA course and follows a structured approach to documenting concepts, lab activities, and practical exercises performed during the learning journey.

## Learning Objectives

The primary goals of this repository are:

- Understand Kubernetes architecture and core concepts.
- Learn how to deploy and manage applications on Kubernetes.
- Gain hands-on experience with cluster administration tasks.
- Develop troubleshooting and operational skills required for production environments.
- Prepare for the Certified Kubernetes Administrator (CKA) examination.
