## Key Concepts

Kubernetes is an open-source container orchestration platform that automates deployment, scaling, and management of containerized applications.

As applications grow, managing containers manually becomes difficult. Kubernetes helps by scheduling workloads, monitoring application health, and recovering failed workloads automatically.

## Why Kubernetes

Some common challenges in containerized environments include:

- Managing large numbers of containers
- Scaling applications during traffic spikes
- Recovering from failures
- Performing rolling updates

Kubernetes provides solutions for these challenges.

## Key Learnings

- Kubernetes is not a container runtime.
- Kubernetes manages containers running on multiple machines.
- It provides self-healing, scaling, and orchestration capabilities.
- Kubernetes has become the industry standard for container orchestration.
